 Statistical Concepts Used

 Mean
Average marks scored by students.

Median
Middle value of the dataset.

 Mode
Most frequently occurring score.

 Variance
Measures how far scores are spread from the average.

 Standard Deviation
Shows the variation in student performance.

 Percentile Rank
Shows the percentage of students scoring below a particular student.

 Key Findings
